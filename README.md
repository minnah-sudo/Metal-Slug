Metal Slug — C++ Game



A 2D action game project developed in C++ using SFML as part of an Object-Oriented Programming (OOP) project.



Technologies Used



\- C++

\- SFML (Simple and Fast Multimedia Library)

\- Visual Studio



Libraries



Standard C++ libraries

\- iostream

\- fstream

\- cmath

\- ctime



SFML modules

\- Graphics

\- Audio

\- Window



Project Structure



\- 25I-0891\_25I-0915\_main.cpp — Main source file

\- 25I-0891\_25I-0915\_Headers/ — Game, Character, Weapon, Enemy, and Collectibles headers

\- 25I-0891\_25I-0915\_Assets/ — Game assets

\- 25I-0891\_25I-0915\_misc/ — Additional project resources



Requirements



\- Visual Studio with a compatible C++ compiler

\- A compatible version of SFML

\- The game assets included in this repository



How to Run



1\. Install Visual Studio with the Desktop development with C++ workload.

2\. Install a compatible version of SFML.

3\. Configure the SFML include directories, library directories, and linker dependencies in Visual Studio.

4\. Open the Visual Studio project or solution.

5\. Build and run the game.



Note: The required SFML version and linker settings must match the version used by this project.



Project Status
